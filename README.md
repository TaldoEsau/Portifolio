# Terminal Tático HoloNet — Esaú Santana

Portfólio em Next.js. O palco interativo fica em `/`. A versão direta, imprimível e sem JavaScript, fica em `/direto`.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`. Copie `.env.example` para `.env.local` quando for ligar Twitch e GitHub. O que ainda falta está em `PENDENCIAS.md`. A especificação está em `SPEC.md`.
